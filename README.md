# COOWIN SEO 内容工作台（v0.2.0 测试版）

这是一个可离线使用的静态 SEO 内容规划工具。直接在 Windows Chrome 中双击 `index.html` 即可运行，无需框架、数据库、联网或服务器。

## 数据范围

- 10 个原始内容集群；160 条文章规划；400 条关键词样本。
- 原始数据位于 `data/demo-data.js`，作为只读研究快照；未经人工核验，不应视为正式 SEO 执行建议。
- 搜索量、KD、原始搜索意图等历史研究数据不可编辑；文章标题、主关键词规划、优先级、工作类型、URL、内容方向、内部链接、备注和状态可以编辑。
- 关键词库支持修改人工归属的目标文章、所属集群、关键词角色及人工备注，不覆盖原始目标页面。

## 操作方法

1. 打开 `index.html`，在「文章管理」里点击「查看 / 编辑」，即可修改文章规划与执行状态。
2. 在「内容集群」点击「编辑集群」，可以修改集群名称、支柱主题与备注；集群 ID 不可变。
3. 在「关键词库」点击「调整归属」，即可选择对应目标文章，保存后会展示人工分配结果。
4. 所有修改自动保存于 Chrome 本地 `localStorage`；页面重新打开时读取同一浏览器、同一页面来源的保存内容。
5. 使用右上角「导出完整备份 JSON」保存独立备份；「导入备份 JSON」可以恢复。**导入将覆盖本地修改**，须先确认。
6. 「重置所有本地修改」会清空文章、集群、关键词三类覆盖数据，恢复演示快照；此操作不可撤销，建议先导出备份。

## 设计与维护原则

- 原始研究快照不可被日常操作污染，所有用户修改存储于独立覆盖层。
- 文章 ID（如 `A001`）、集群 ID（如 `C01`）保持稳定。关键词样本目前使用固定数组下标作为索引，因此替换关键词样本集之前需要迁移编辑数据。
- 修改内容不会自动写回 GitHub、`demo-data.js` 或 WordPress，也不会跨电脑同步。不能将 localStorage 当作唯一备份。
- 备份 JSON 包含的是**本地修改覆盖层**（完整的用户编辑记录），需要同一版本的原始演示数据才可以恢复，并非独立于原始数据的 160 篇完整文章导出。
- 仍未支持添加或删除文章、批量编辑、版本历史、联网协作与实时 SEO 数据更新。
- 本版本是测试版，发布正式版本前建议在目标 Windows Chrome 环境中测试编辑、刷新、导出、导入和恢复流程。
